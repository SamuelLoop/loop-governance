## Source of the glyph

`icon-mark-*.png` / `icon-mark.svg` are cropped directly from the existing
`apps/portal/public/logo-full.png` infinity glyph (Loop Cmbntr's shipped
marketing icon) — not redrawn. Two reasons:

1. It's already blue-violet chrome (`#4f6bff`-ish through `#8b5cf6`-ish),
   which happens to sit almost exactly on Signal Pulse's accent gradient
   without any recolouring. That's a genuine, load-bearing continuity
   point for the mobile/web-relationship decision in
   `sessions/web-brand-output.md` §1 — not a coincidence worth ignoring.
2. Redrawing a 3D twisted-chrome infinity loop as flat vector paths would
   be a worse asset than the one already sourced and already invested in.

Honesty note: this makes the icon a **raster asset**, not a true vector.
`icon-mark.svg` is a thin SVG wrapper (a `<image>` embed of the PNG as a
base64 data URI) so it can be dropped in anywhere an `<img>` or inline SVG
is expected, but it does not scale losslessly past ~512px source
resolution. If the platform ever wants the glyph past business-card/app-
icon scale (e.g. a large hero illustration), it needs a real redraw —
out of scope for this session, flagging for whenever that need arises.
